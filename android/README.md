# Neon Lite для Android · 0.4.0

Независимый прототип рядом с Windows-сборкой mpv Neon v12. Один APK для Android 7.0+ на телефоне, планшете и Android TV. «Авто» выбирает интерфейс по типу устройства; его можно переопределить на главном экране. На ТВ виден фокус, кнопки доступны с D-pad, аппаратные кнопки воспроизведения поддерживаются.

- **SMB2/SMB3:** укажите адрес и имя общей папки или полный путь `smb://192.168.1.20/Video`. Вход гостем или с логином, паролем и необязательным доменом. Можно открыть папку, выбрать медиафайл и перематывать без предварительной загрузки всего файла.
- **TorrServer:** подключение по HTTP(S), без авторизации или с HTTP Basic. Приложение показывает торренты, уже добавленные на сервер, и их файлы. По HTTP используйте пароль только в доверенной сети; HTTPS предпочтительнее.
- **Найти в локальной сети:** проверяет до 254 адресов в непосредственно подключённой частной IPv4-подсети. SMB предлагается по порту 445; для TorrServer проверяется `/echo` на портах 8090, 8099 и 5665. Серверы, ответившие HTTP 401, показываются как возможные. Для другой подсети, нестандартного порта, DNS-имени или IPv6 используйте ручной ввод. Обнаружение SMB-сервера пока не перечисляет его общие папки: имя папки нужно указать вручную.
- Воспроизведение использует MediaPlayer Android. Поддержка видео, звука и субтитров зависит от устройства. Windows-сборка mpv, шейдеры, сторонние декодеры и сам TorrServer в APK не входят.
- Пароли хранятся только в памяти. Приложение сохраняет настройки интерфейса и SBS.

## Настройки приложения и управление

**Настройки** доступны на главном экране. Здесь можно выбрать интерфейс для ТВ или телефона, тему **YouTube / Neon**, задержку скрытия панели и начальную скорость. Тема YouTube использует тёмное оформление, белые кнопки и красную шкалу воспроизведения.

Панель поверх видео исчезает по таймеру (по умолчанию через 3 секунды) и не меняет размеры кадра. Открытые настройки и пауза оставляют панель видимой. На телефоне касание видео прячет или возвращает панель. На ТВ стрелки возвращают управление; когда панель скрыта, OK ставит видео на паузу и открывает её, а ← / → перематывают. «Назад» закрывает открытые настройки или скрывает панель. При раздельном выводе управление остаётся на том экране, на котором открыт плеер.

- **Кадр:** Вписать, По ширине, По высоте, Заполнить с обрезкой или Растянуть. В общих настройках задаётся начальный режим; **⚙ → Кадр** меняет его для текущего видео. В SBS выбранный размер применяется отдельно к каждому глазу.
- **Дорожки:** через **⚙ → Дорожки** можно переключать встроенный звук и доступные текстовые субтитры, отключать субтитры и открывать внешний SRT. Поддержка встроенных дорожек зависит от декодеров Android; внешний звук, ASS-оформление и графические субтитры в Lite не добавлены.
- **Плейлисты:** файлы текущей папки SMB или открытого торрента образуют очередь с переходом к следующему. **Мои плейлисты** на главном экране управляют сохранёнными списками, а **⚙ → Плейлист** добавляет текущий файл и включает повтор.
- **Продолжить просмотр:** позиция сохраняется для локальных файлов, SMB и TorrServer. Пункт «Продолжить» открывает последний недосмотренный файл. Историю позиций можно отключить или очистить. Пароли защищённых источников не сохраняются; при повторном открытии может потребоваться вход.

## Очки XREAL и 3D

В **Настройки → SBS и очки** задаются начальный формат, вывод, эффект и сила сглаживания. Автовключение SBS при **3840 × 1080** можно выбрать вместо обычного 2D. Во время видео эти параметры доступны через **⚙**. Режим самих очков меняется на очках.

- **2D** — обычное воспроизведение. **2D → SBS** — одинаковый кадр для обоих глаз; объём объектов в плоском ролике не синтезируется.
- **SBS Half** — для стереовидео со сжатыми по ширине кадрами для каждого глаза. **SBS Full** — для стереовидео с двумя полноразмерными кадрами. Примеры форматов: [руководство XREAL по SBS](https://tutorials.xreal.com/docs/glasses/one-series/osd/3d-mode/).
- **Виньетка** затемняет границы. **Мягкие края + перспектива** добавляет плавный переход в чёрный, небольшое размытие и сужение дальней стороны кадра. Эффект выключается или регулируется ползунком.
- Если Android предоставляет очки как отдельный дисплей, SBS-видео выводится на него, а телефон остаётся пультом. Кнопка **Чёрный экран телефона** скрывает управление; касание или «Назад» возвращает его. После отключения очков управление возвращается автоматически.
- Если доступно только зеркалирование, плеер дублирует панель воспроизведения вместе с SBS на одном экране. Отдельно затемнить телефон в этом режиме нельзя: очки получают ту же картинку. Заполнение дисплея зависит от того, как телефон зеркалирует изображение.
- На Android TV с очками как единственным HDMI-экраном используется SBS на основном дисплее: панель для обоих глаз скрывается одновременно, кадр остаётся полноразмерным. Если приставка не сообщает **3840 × 1080**, SBS можно включить вручную; это само по себе не меняет HDMI-разрешение.

Для SBS используется один аппаратный или системный декодер Android и вывод через OpenGL ES. Отдельной копии потока для второго глаза нет.

## Сборка

Android Studio: открыть папку `android`, выбрать JDK 17 и Android SDK 35, собрать вариант debug. С установленным Gradle 8.9+:

```powershell
gradle :app:assembleDebug
```

Альтернативная сборка на Windows без Gradle, использованная для APK прототипа: Android SDK 35, Build Tools 35.0.0, JDK 17, Python 3.11+ и curl.exe. При необходимости задайте `ANDROID_HOME` и `JAVA_HOME`.

```powershell
python build-with-sdk.py
```

APK появится в `build/sdk-tools/neon-android-debug.apk`. Используется локальный ключ для тестовой подписи. Для публикации потребуется собственный релизный ключ.

Windows-файлы в этот модуль не перенесены. См. `THIRD-PARTY.txt` для зависимостей.
