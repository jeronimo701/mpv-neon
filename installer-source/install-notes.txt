mpv Neon — публичная сборка, версия 6

Установка для текущего пользователя, без прав администратора.
Плеер добавляется в «Открыть с помощью» и список приложений по умолчанию.
Текущие приложения по умолчанию НЕ заменяются. VLC, KMPlayer и другие плееры остаются как есть.

Для постоянного выбора плеера используйте «Открыть с помощью → Выбрать другое приложение → Всегда» или настройки приложений по умолчанию Windows.

F12 или «Настройки → Оформление»: Glass (основной), Deck в духе Steam Deck, Neon под иконку №07, Стандартный uosc. Регулируются акцент, плотность панелей, размер текста и анимация. Glass использует прозрачность и декоративные блики, без настоящего размытия/преломления видео под панелью. Цветная рамка отключена, мелкие подписи увеличены. Профили апскейла: F2 или кнопка HQ внизу.
Внизу — горизонтальный ползунок громкости и кнопка выключения звука. Колесо над видео меняет громкость на 5%, над меню прокручивает список.

Настройки, история, закладки и собственные пресеты существующей установленной копии сохраняются при обновлении. При удалении личные данные остаются в папке установки; при желании их можно удалить вручную.
Настройки из отдельной portable-копии автоматически не переносятся.

TorrServer: сначала используется уже работающий сервер. Встроенный запускается при необходимости. Службы Windows и автозапуск не добавляются.

В этой публичной сборке нет Lossless.dll. LSFG требует собственную совместимую библиотеку из лицензированной установки пользователя. Без неё обычное воспроизведение, интерфейс и шейдеры доступны, но генерация кадров LSFG не работает.

Собственной цифровой подписи у установщика нет. Windows может показать предупреждение о неизвестном издателе.
