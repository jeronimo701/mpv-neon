mpv Neon v11.4 — публичная сборка

После опубликованной v6:
- Тема YouTube и доработки интерфейса, меню и громкости; Deck по умолчанию.
- SponsorBlock в меню ПКМ: категории, пропуск/ускорение/метки.
- Внешние аудиодорожки рядом с видео и в непосредственных подпапках.
- Поддержка русской раскладки для горячих клавиш.
- Portable, установка для текущего пользователя и установка для всех пользователей.
- Сохранение пользовательских настроек, резервные копии и новые образцы defaults.
- Исправлен ранний перезапуск установщика через Windows ShellExecuteW.
- Встроен стартовый логотип; при обновлении останавливается только TorrServer из выбранной папки.
- Сохраняется mpvNeon.Personal для обновления существующей установки v6.

Публичный пакет не содержит Lossless.dll, личных настроек, истории и кэшей.
LSFG без собственной совместимой DLL недоступен.
Запуск: mpv-neon.exe или Start.cmd.
