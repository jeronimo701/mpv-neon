# Установка mpv Neon v6 — публичная версия

Запустите `mpv-Neon-Setup-v6-public.exe`. По умолчанию установка выполняется только для текущего пользователя в `%LOCALAPPDATA%\Programs\mpv Neon`, без прав администратора. Можно выбрать ярлык и добавление в «Открыть с помощью»/список приложений по умолчанию.

Текущий плеер по умолчанию принудительно не заменяется. Чтобы выбрать mpv Neon, используйте меню Windows «Открыть с помощью → Выбрать другое приложение → Всегда» или настройки приложений по умолчанию.

После установки используйте mpv-neon.exe. Системные службы, глобальный PATH и автозапуск не добавляются. При обновлении сохраняются существующие mpv.conf, input.conf и script-opts; новые значения по умолчанию может потребоваться объединить вручную. История, закладки, пресеты и база TorrServer не входят в дистрибутив и создаются локально. Отдельная portable-копия автоматически не мигрирует.

**Lossless.dll не включена.** Без собственной совместимой лицензированной DLL пользователя генерация кадров LSFG недоступна; обычное воспроизведение и интерфейс работают без неё. Проект не загружает платную библиотеку. Собственную DLL и её зависимости нельзя автоматически считать разрешёнными к дальнейшему распространению.

Установщик не имеет доверенной подписи издателя. Windows SmartScreen может показать предупреждение; сверяйте SHA-256 с релизом. Контрольная сумма не заменяет цифровую подпись.

Публичный установщик собран Inno Setup 7.1.0, но не запускался на основной системе при подготовке релиза. Результаты и ограничения проверки — PUBLIC-VALIDATION.md в репозитории https://github.com/jeronimo701/mpv-neon .
