# Установка mpv Neon v12

Запустите `mpv-Neon-Setup-v12-public.exe`. Мастер предлагает три режима:
- Portable: отдельная папка, без регистрации приложения и ассоциаций Windows.
- Для текущего пользователя: без прав администратора.
- Для всех пользователей: с запросом UAC; настройки каждого пользователя хранятся отдельно.

Для обновления выберите прежний режим и папку. Перед заменой файлов установщик останавливает только TorrServer из этой папки. Пользовательские настройки сохраняются; создаётся резервная копия portable_config. Изменённые пользователем конфиги не заменяются автоматически: новые образцы помещаются в new-defaults. Старый Player.exe удаляется; запускайте mpv-neon.exe или Start.cmd.

v12: YouTube — тема по умолчанию новой конфигурации. Если тема уже сохранена, выберите YouTube через F12. Звук: F5 → «Звук»; несколько плейлистов: F5 → «Мои плейлисты». Настройки звука, playlists.json и свои пресеты остаются личными файлами и не заменяются установщиком. При пользовательском input.conf новые сочетания могут потребовать ручного добавления; пункты F5/ПКМ доступны независимо от новых сочетаний. Новые скрипты и defaults обновляются launcher при следующем запуске.

Это локальная сборка на базе GitHub v11.4; новый релиз в GitHub автоматически не публиковался. Проверки новых функций и ограничения — docs/V12.md внутри плеера.

Установленная версия хранит профиль в `%LOCALAPPDATA%\mpv Neon\Profiles\user` или `all`. Portable хранит настройки рядом с плеером. При переходе между режимами проверьте перенос настроек отдельно. Установка v6 обновляется режимом «для текущего пользователя» в её прежнюю папку.

Добавление в «Открыть с помощью» и ярлык выбираются в мастере. Windows UserChoice принудительно не меняется.

**Lossless.dll отсутствует.** LSFG требует собственную совместимую библиотеку пользователя, полученную законным способом. Проект не скачивает платную DLL; обычное воспроизведение работает без неё.

Установщик не подписан доверенным сертификатом. Сверяйте SHA-256 с релизом. Результаты проверок и ограничения: https://github.com/jeronimo701/mpv-neon/blob/main/PUBLIC-VALIDATION.md .
