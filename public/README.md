# mpv Neon v6 — публичная сборка

Русский интерфейс uosc, темы Glass/Deck/Neon, управление громкостью, шейдеры и TorrServer на базе mpv. Основной движок mpv не переделывался этим пакетом; Player.exe служит запускателем.

Запуск portable: Player.exe или Start.cmd. После установки: mpv-neon.exe. F12 — оформление, F2 — шейдеры, F3 — TorrServer, F5 — настройки, F10 — таймер. Space — пауза, F/двойной клик — полный экран.

**В публичной версии нет Lossless.dll.** LSFG требует собственную совместимую библиотеку из лицензированной установки пользователя; без неё обычное воспроизведение остаётся доступным. Проект не скачивает платную DLL. Нативный модуль не изменяет Steam-установку. Эффективная частота LSFG и совместимость GPU требуют отдельной проверки.

Из пакета исключены личные JSON-настройки, история, watch_later, кэши, базы TorrServer и отладочные файлы. Новые пользовательские данные создаются локально. TorrServer по умолчанию использует loopback; удалённый адрес/учётные данные задайте самостоятельно.

Существующие mpv.conf/input.conf/script-opts при установке поверх предыдущей версии сохраняются. При изменении значений по умолчанию их может потребоваться объединить вручную. Автоматического обновления всей сборки нет; updater.bat в portable, если присутствует, относится к движку mpv, а не всем дополнениям.

Источники и лицензии: docs/SOURCES.json, docs/licenses/ и THIRD-PARTY.md. Исходники дополнительных модулей — native/. Репозиторий: https://github.com/jeronimo701/mpv-neon . Сборка — самостоятельная компоновка сторонних компонентов, не форк ядра mpv.

Установщик и launcher не имеют доверенной подписи издателя. Проверяйте SHA-256 релиза. Сборка и программные smoke-тесты не гарантируют все сочетания GPU, шейдеров, внешних сайтов и сервера TorrServer.
