# Проверки публичной сборки v12

Дата проверки публикации: 2026-10-23. Основа — опубликованная v11.4,
commit `c448d2078fcaa781ada9541a2701e1c736ef5e2a`. Изменения перенесены из
отдельной рабочей копии автора в свежий clone; исходные папки не изменялись.

## Повторено перед публикацией v12

- Проверен именно чистый `mpv-neon-v12-portable`, 350 файлов: нет Lossless.dll,
  истории, библиотек/личных JSON-настроек, кэшей и баз TorrServer. Исходная
  установленная папка с пользовательскими данными не использовалась как payload.
- validate-public.ps1: обязательные файлы, лицензии, анонимный loopback,
  defaults.sha256 — PASS. Проверка UTF-8: 158 файлов интерфейса PASS.
- Все 6 PowerShell-файлов разобраны через AST, Python-сценарии синтаксически
  проверены. Launcher.cs и PlaylistWindow.cs повторно скомпилированы системным
  C# compiler в отдельную scratch-папку. Включённые Lua/C/C#/headers/configs/shaders
  в исходном дереве по SHA256 совпали с чистым payload; файлы автора не заменялись.
- SHA256 готового установщика и готового Portable ZIP совпали с отчётом автора.
  ZIP открыт и все 350 распакованных потоков по SHA256 совпали с чистой папкой.
  Архив содержит OEM CP866-имена двух русских TXT; для точной проверки использована эта кодировка.
- `tests/smoke-public.py` запущен заново с настоящим публичным установщиком:
  изолированное Portable-обновление, остановка только встроенного тестового
  TorrServer, сохранение изменённых input.conf/ui-theme.json и побайтовое
  совпадение остальных файлов с payload — PASS. Ассоциации/ярлыки не создавались;
  настоящая установленная копия пользователя не менялась.
- Синтетическое воспроизведение через null audio/video output — PASS,
  Lua errors/stack traceback нет, exit 0. Без Lossless.dll модуль сообщил
  ожидаемую недоступность, плеер остался отзывчивым.
- Launcher подготовил профиль через MPV_NEON_PROFILE_ROOT в отдельной тестовой
  папке: сохранение настроек, build-id v12 и связь с тестовым runtime — PASS.
- Именованные плейлисты проверены ещё раз двумя отдельными процессами:
  создание/переключение независимых списков, восстановление очереди, выбранного
  файла, времени и паузы. Обе фазы PLAYLIST_FAILURES=0.
- Gitleaks 8.30.1: две находки в копиях uosc main.lua — один неизменённый публичный
  OpenSubtitles application key, повторно сравненный с официальным upstream uosc
  5.13.0 без вывода значения. Других находок сканера нет. Это не гарантия
  обнаружения всех возможных секретов.
- Просмотрены три предоставленных снимка самого mpv на синтетическом видео:
  звук, библиотека и буфер макетного TorrServer. Захват рабочего стола не использовался.

В подготовительном отчёте автора отдельно указаны AUDIO_FAILURES=0, проверки
12 Anime4K GPU-цепочек, сохранности библиотеки и макетного TorrServer. Они
сохранены как результаты подготовки v12, **не заявляются повторным аппаратным
тестом в ходе публикации**. Сценарии находятся в tests/v12/.

## Исторический отчёт v11.4 (не результаты v12)

Дата: 2026-10-22, Windows x64. Исходный личный пакет и старые релизы не изменялись.

- Подготовлен отдельный публичный payload: 343 файла. Lossless.dll, личные JSON-настройки, история, watch_later, кэши, базы TorrServer и отладочные файлы отсутствуют. TorrServer настроен на анонимный loopback. Восстановлены сторонние лицензии; LICENSE.txt и LICENSE-SCOPE.md включены. Ограничительная лицензия относится только к перечисленным собственным материалам, не к mpv/uosc и их модификациям.
- Сохранены исходники Lua/C, нового C# launcher и установщика. SOURCES.json содержит актуальную версию сборки и локальные изменения. Крупные исполняемые зависимости в Git не включаются.
- prepare-public.ps1 создаёт новую папку, исключает личные данные и linked paths, восстанавливает уведомления и пересчитывает defaults.sha256. validate-public.ps1 проверяет обязательные файлы, отсутствие личных данных, anonymous loopback и SHA-256 всех defaults-файлов.
- Launcher собран системным .NET Framework csc.exe из installer-source/Launcher.cs; установщик — установленным Inno Setup 6. Перед запуском ISCC.exe проверена действующая Authenticode-подпись Pyrsys B.V. Итоговый установщик не подписан доверенным сертификатом издателя.
- Все 6 PowerShell-файлов разобраны без синтаксических ошибок. Python smoke-тест и проверка кодировки прошли py_compile. Проверено 152 UTF-8 файла интерфейса.
- Gitleaks 8.30.1 проверил исходники и полный публичный payload. Найдено по два вхождения публичного OpenSubtitles application key uosc (portable_config и defaults). Значение без вывода сравнено с официальным uosc 5.13.0 src/uosc/main.lua: совпало. Других находок нет. Это не гарантия обнаружения всех возможных секретов.
- Итоговый публичный EXE запущен в отдельную папку с кириллицей и пробелами, /CURRENTUSER /MODE=portable, без ярлыков и ассоциаций. Перед обновлением там работал настоящий локальный TorrServer на loopback: он остановлен перед заменой файлов. Пользовательские input.conf и тема YouTube сохранены; все прочие установленные файлы побайтно совпали с payload. Установочная запись и uninstaller для Portable не создавались; Lossless.dll и прежний Player.exe отсутствуют.
- Из распакованного публичного EXE mpv.com воспроизвёл синтетический чёрный клип с null video/audio output и конфигами/скриптами сборки. Прогресс подтверждён через IPC. Ошибок Lua/stack traceback нет, exit 0. Это не визуальная проверка GPU/интерфейса.
- Native-модулю передан lsfg-native-probe без Lossless.dll. Он сообщил об отсутствии DLL; плеер остался отзывчивым. Работающая генерация кадров этим не подтверждается.
- Скомпилированный launcher подготовил установленный профиль в отдельной папке через MPV_NEON_PROFILE_ROOT и --neon-prepare-only. Пользовательские настройки сохранены, build-id применён, runtime указывает на тестовую папку. Настоящая пользовательская установка и профиль не менялись.

Повторить из корня репозитория; выход теста должен быть новой папкой:

```powershell
python tests/smoke-public.py --payload D:/build/mpv-v11.4-public --installer D:/build/mpv-Neon-Setup-v11.4-public.exe --work D:/build/test-v11.4
```

SHA-256 итогового EXE опубликован в SHA256SUMS.txt. Предыдущие личные проверки в installer-source/VALIDATION.txt не подменяют проверку публичного пакета.

Не проверены: реальный UAC и установка для всех пользователей, полный системный install/upgrade/uninstall, аппаратный GPU/HDR/LSFG, все внешние сайты и длительное воспроизведение. Основная пользовательская установка и системные ассоциации не изменялись.
