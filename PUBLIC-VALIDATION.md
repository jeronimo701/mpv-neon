# Проверки публичной сборки v6

Дата: 2026-10-21, Windows x64.

- Создана отдельная копия готовой v6; личная исходная portable-папка и прежние установщики не изменены.
- Скрипт prepare-public.ps1 выполнен на полной папке. В публичном payload 199 файлов; Lossless.dll, история, watch_later, кэши, базы TorrServer, пользовательские JSON и Player.pdb отсутствуют. Сервер по умолчанию — анонимный loopback, без домашних адресов и учётных данных.
- validate-public.ps1 проверяет обязательные файлы, manifest и файл-список Inno Setup. Build.ps1 дополнительно отказывается собирать payload при наличии Lossless.dll.
- PowerShell-скрипты подготовки/сборки прошли синтаксический разбор.
- Использован Inno Setup 7.1.0; перед запуском проверена действующая Authenticode-подпись Pyrsys B.V. Компиляция публичного установщика завершилась успешно. После обновления вложенной инструкции установщик пересобран. Файл mpv-Neon-Setup-v6-public.exe: 119084750 байт, SHA-256 `c59deae47626ed83996820761a8179e8457beadc4ec59f2e9d1fad700a19bf64`.
- Установщик не запускался на основной системе: текущие ассоциации и установленная пользовательская копия не менялись. Новый install/upgrade/uninstall цикл публичного установщика не заявляется проверенным; ранние личные тесты не подменяют такую проверку.
- В отдельной smoke-копии mpv.com воспроизвёл синтетический чёрный клип с null video/audio output, с конфигами и скриптами этой сборки; exit 0, error/fatal сообщений не было. Это не визуальный тест uosc, GPU или шейдеров.
- Отдельный тест послал native-модулю LSFG запрос probe при отсутствующей Lossless.dll. Плагин сообщил об отсутствии библиотеки; плеер остался работоспособным и завершился exit 0. Отсутствие этой DLL не заявляется работающим LSFG.
- Gitleaks 8.30.1: одно срабатывание на OpenSubtitles application key в uosc. Значение без вывода сравнили с официальным upstream uosc 5.13.0: оно совпадает с публично поставляемым ключом приложения, не является личным ключом владельца сборки. Других находок исходников не было. Такая проверка не является гарантией обнаружения всех возможных секретов.
- Тексты сторонних лицензий, ссылки и версии сохранены. Исходники скриптов, launcher и native-модуля опубликованы отдельно от крупных сторонних binaries. Единая новая лицензия всему набору не назначалась.

Остаётся проверять на целевой машине: интерфейс и темы, реальные видеокодеки/GPU/шейдеры, внешние сайты, TorrServer, установки/обновления с пользовательскими конфигами, цифровую подпись и совместимость необязательной пользовательской LSFG-библиотеки.
