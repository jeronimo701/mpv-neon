# mpv Neon

Плеер для Windows на базе **mpv** с доработанным интерфейсом **uosc**. Темы оформления, библиотека плейлистов, настройки звука и изображения, сетевое видео — в одной готовой сборке.

**Windows x64 · версия v12 · установщик или Portable**

[Скачать v12](https://github.com/jeronimo701/mpv-neon/releases/tag/v12) · [Установка и обновление](public/INSTALLER.md) · [Что нового](mpv-portable/docs/V12.md) · [Сообщить о проблеме](https://github.com/jeronimo701/mpv-neon/issues)

*Захват настоящего окна mpv на синтетическом видео, без личных файлов и рабочего стола.*

## Для чего пригодится

- Смотреть локальные файлы и поддерживаемое сетевое видео.
- Выбирать тему: YouTube, Neon, Glass или Deck.
- Настраивать нормализацию, усиление с лимитером, ночной режим и аудиоустройство.
- Переключать Anime4K и другие доступные шейдеры из меню.
- Сохранять очереди в именованные плейлисты с позицией воспроизведения.
- Работать с TorrServer и видеть подготовку стартового буфера.

## Установка за минуту

1. Скачай `mpv-Neon-Setup-v12-public.exe` или `mpv-neon-v12-portable.zip` из [релиза v12](https://github.com/jeronimo701/mpv-neon/releases/tag/v12).
2. В установщике выбери Portable, текущего пользователя либо всех пользователей. Последний вариант требует UAC.
3. Запусти `mpv-neon.exe` или `Start.cmd` и перетащи видео в окно.

Portable ZIP распаковывай в отдельную папку. При обновлении сначала сохрани независимую копию настроек и используй прежний режим установки. Если архиватор искажает русские имена TXT (CP866), используй установщик в режиме Portable.

## Основные клавиши

| Клавиша | Действие |
| --- | --- |
| F12 | Темы |
| F2 | Изображение и шейдеры |
| F3 | TorrServer |
| F4 | Качество сетевого видео |
| F5 | Настройки |
| Ctrl+Shift+A | Звук |
| Ctrl+Shift+P | Библиотека плейлистов |
| Ctrl+P | Отдельное окно плейлистов |
| A / Ф | Аудиодорожки |

## Что важно знать

**Lossless.dll не входит в комплект.** Без собственной совместимой лицензированной библиотеки LSFG недоступен; обычное воспроизведение от неё не зависит. Реальная производительность Anime4K/LSFG зависит от GPU.

Личные история, закладки, настройки и база TorrServer исключены. Сетевые функции зависят от внешних сайтов. Установщик не имеет доверенной подписи издателя — сверяй SHA256 в релизе.
