перелицензирует mpv, uosc, их модификации, TorrServer и прочие компоненты.
Папка `mpv-portable/` полностью исключена из области новой лицензии.

Самостоятельная Windows x64 сборка на базе mpv: русскоязычный интерфейс uosc, темы Glass/Deck/Neon, шейдеры, TorrServer и дополнительные инструменты. Это не форк ядра mpv: собственный запускатель вызывает mpv.exe; изменения интерфейса и скрипты поставляются отдельно.

## Установка

Готовая публичная версия находится в [Releases](https://github.com/jeronimo701/mpv-neon/releases). Скачайте `mpv-Neon-Setup-v6-public.exe`. Установщик работает для текущего пользователя; можно добавить ярлык и пункт «Открыть с помощью». Принудительной замены приложений по умолчанию нет.

Установщик не подписан доверенным сертификатом; Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 с опубликованным файлом контрольных сумм. После установки запускайте `mpv-neon.exe`. Приложение не имеет автоматического обновления всей этой сборки.

## Важное отличие публичной версии

**Lossless.dll из платного Lossless Scaling не включена** ни в Git, ни в установщик. Личные конфиги, история просмотра, watch_later, кэши и базы TorrServer также не включены. Без собственной совместимой лицензированной DLL режимы LSFG недоступны; обычное воспроизведение, темы и шейдеры от неё не зависят. Не обещается совместимость со всеми версиями Lossless Scaling и GPU.

В сборке сохранён исходник необязательного LSFG-модуля и ссылка на использованный ABI reference. Библиотека должна быть получена пользователем законным способом; этот проект её не скачивает и не активирует. Обычный запуск не запускает Lossless Scaling.

## Возможности и управление

- F12 — темы Glass, Deck, Neon и стандартная; горизонтальная громкость, увеличенные элементы управления.
- F2 — профили изображения/шейдеров: обычный, RAVU, FSRCNNX, Anime4K. Тяжёлые режимы требуют подходящего GPU.
- F3 — TorrServer, F4 — качество сетевого видео, F5 — настройки.
- Space — пауза, двойной клик/F — полный экран, J/L — ±10 секунд, колесо — громкость.
- F8 — заполнение чёрных полос, F9 — сравнение до/после, F10 — таймер сна, B — закладки.
- История, пользовательские настройки и закладки создаются локально после запуска.

Glass — декоративная прозрачность/блики, не настоящее размытие изображения под интерфейсом. LSFG-статус не является измерением фактической частоты сгенерированных кадров. Доступность сетевых сайтов/сервисов не гарантируется.

## Что хранится в репозитории

Исходники/настройки в `mpv-portable/`, код launcher/native-модуля и скрипты установщика. Тяжёлые сторонние исполняемые файлы размещаются в готовом установщике, не в Git. Версии, первичные проекты и ссылки на исходники перечислены в `mpv-portable/docs/SOURCES.json`; тексты лицензий — в `mpv-portable/docs/licenses/` и [THIRD-PARTY.md](THIRD-PARTY.md). Изменённые части uosc перечислены в SOURCES.json. Нельзя считать весь набор кодом одного автора или автоматически назначать ему MIT-лицензию.

## Сборка публичного установщика

Для сборки нужен Windows PowerShell/PowerShell 7, Inno Setup 7 и полная подготовленная папка плеера с зависимостями версий из SOURCES.json. В Git эти binaries намеренно не включены. Получайте их из указанных первичных источников; не используйте личную папку как payload без очистки.

```powershell
# Из полной локальной папки создать новую очищенную копию; существующий выход не перезаписывается.
.\prepare-public.ps1 -InputPlayerRoot 'D:/path/to/full-player' -OutputPlayerRoot 'D:/build/mpv-Neon-v6-public'

# Компилятор получите из официального Inno Setup. Сам установщик здесь не запускается.
.\installer-source\build.ps1 -Compiler 'C:/path/to/ISCC.exe' -PlayerRoot 'D:/build/mpv-Neon-v6-public' -BuildRoot 'D:/build/inno-temp' -OutputRoot 'D:/build/release'
```

`native/BUILD.md` внутри mpv-portable описывает сборку launcher и дополнительного модуля с Zig. Точная совместимость пользовательских настроек при обновлении требует проверки; существующие mpv.conf/input.conf/script-opts установщик не заменяет. Новые настройки может потребоваться объединить вручную.

## Проверки публичного выпуска

См. `PUBLIC-VALIDATION.md`: исключение частных файлов, сканирование исходников, сборка установщика и smoke-проверки. Наличие успешной компиляции не означает проверку всех эффектов на реальном GPU. Публичная версия не содержит личную DLL, использованную в прежних частных тестах.
